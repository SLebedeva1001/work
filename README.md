# Supplier Kanban
=======
# Распределение поставщиков

Общая канбан-доска для распределения поставщиков между менеджерами.

## Локальный запуск

Нужен Node.js 18 или новее.

```bash
npm start
```

После запуска откройте `http://localhost:3000`.

## Хранение данных

Доска хранится в `data/board.json`. Для хостинга с постоянным диском можно указать
другой путь переменной окружения `DATA_FILE`, например `/var/data/board.json`.

API:

- `GET /board` — получить состояние;
- `POST /board` — сохранить состояние.

Для командного использования выбирайте хостинг с постоянным диском (например,
Render Persistent Disk или Railway Volume). На эфемерной файловой системе
изменения могут исчезнуть при новом деплое.

В репозитории есть готовый `render.yaml`: при создании Render Blueprint он
поднимет веб-сервис и подключит постоянный диск `/var/data`.
