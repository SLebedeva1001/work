# Baby Trend · рабочее пространство закупок

Внутреннее React-приложение для задач команды, сотрудников и поставщиков.

## Возможности

- задачи с несколькими текущими исполнителями;
- история обновлений, передач и статусов по датам;
- активные задачи и автоматический архив завершённых/отменённых;
- фильтры по сотруднику и статусу;
- справочник поставщиков: доставка, отсрочка, категории, бренды, контакты и примечания;
- доска распределения поставщиков между закупщиками;
- сотрудники, роли администратора и приглашения по электронной почте;
- Supabase Auth и общее хранение данных в Supabase.

## Защита существующих данных

При первом открытии новой версии сервер читает текущую запись `board_state/main`, создаёт отдельную резервную запись `backup-<timestamp>` и только затем формирует новое рабочее пространство в `board_state/workspace`. Исходные поставщики и распределение не удаляются.

Новая версия также обновляет совместимую запись `board_state/main`, поэтому старую доску можно восстановить без обратной миграции.

## Локальный запуск

```bash
npm install
npm run build
npm start
```

Без переменных Supabase приложение использует локальный файл и автоматически входит как администратор. Это предназначено только для разработки.

## Переменные окружения

Скопируйте `.env.example` и задайте значения на хостинге:

- `SUPABASE_URL` — URL проекта Supabase;
- `SUPABASE_SERVICE_ROLE_KEY` — серверный service role key, никогда не передаётся в браузер;
- `ADMIN_EMAIL` — почта первого администратора;
- `APP_URL` — публичная ссылка приложения для писем-приглашений.

## Первый вход

1. На экране входа нажать «Первый вход администратора».
2. Указать почту из `ADMIN_EMAIL` и придумать пароль не короче 8 символов.
3. После входа открыть «Сотрудники», добавить почту коллеги и нажать «Пригласить».

Пароли хранит и проверяет Supabase Auth. Само приложение их не сохраняет.

## Размещение

- Render: настройки находятся в `render.yaml`.
- Vercel: маршрутизация фронтенда и API находится в `vercel.json` и `api/index.js`.
