# Инструкции для Codex

Этот репозиторий содержит рабочее пространство Baby Trend: React-интерфейс, Node.js API, Supabase Auth и общее хранилище данных Supabase.

## Перенос и запуск на macOS

1. Полностью прочитайте `НАЧАТЬ_ЗДЕСЬ.txt`, если он находится рядом с проектом, и `MAC_SETUP.md`.
2. Требуется Node.js 20.19 или новее; рекомендуется Node.js 22 LTS.
3. Проверьте права и окончания строк файлов `setup-mac.command` и `start-workspace.command`.
4. Для первоначальной установки запустите `./setup-mac.command`.
5. Реальные параметры Supabase пользователь вводит в локальный `.env`. Не просите помещать их в Git и не выводите значения секретов в терминал или сообщения.
6. Для запуска используйте `./start-workspace.command`; локальный адрес по умолчанию — `http://localhost:3000`.

## Данные и безопасность

- Рабочие задачи, сотрудники и поставщики находятся в Supabase в `board_state/workspace`.
- Пользователи находятся в Supabase Auth.
- GitHub и папка переноса содержат программу, но не рабочую базу, пароли или service-role key.
- Без Supabase приложение создаёт отдельные локальные файлы `data/board.json` и `data/board.json.workspace.json`; они исключены из Git.
- Не изменяйте и не удаляйте рабочие данные Supabase, настройки Render или пользователей без прямого подтверждения пользователя.
- Не добавляйте в Git `.env`, резервные копии базы, логи, `node_modules`, `dist` или пользовательские выгрузки.

## Проверка изменений

Перед публикацией выполните:

```bash
npm install
npm run build
node --check server.js
```

Рабочая версия размещена на Render по адресу `https://work-uw04.onrender.com/`. Render собирает `dist` автоматически из исходников после обновления ветки `main`.
